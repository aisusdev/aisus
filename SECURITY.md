# Security policy

Report a security problem privately. Open the repository's **Security** tab and choose **Report a vulnerability**. The report reaches only the maintainers. Please keep it out of public issues until a fix is released.

Include what you found, the steps to reproduce it and the version of aisus you used. A maintainer replies within seven days, agrees a date for the fix with you and credits you in the release notes unless you would rather not be named.

## Supported versions

Fixes go into the newest release. The extension, the IntelliJ plugin, the CLI and the GitHub Action are released together, so updating to the latest release picks up every fix. aisus cloud at aisus.dev always runs the newest code.

## What is in scope

- The VS Code extension, the IntelliJ plugin, the CLI and the agent skills.
- The GitHub Action.
- aisus cloud, including its upload tokens, share links and sign-in.

Problems in the coding agents that aisus starts, such as Claude Code or Codex, belong to those agents' own projects.
