    1. Install the aisus extension.

    2. Open checkout-service in VS Code. Press Generate in the aisus sidebar.
    3. Commit the map folder.
      $ git add .archify && git commit -m "Add aisus map" && git push
    1. In the repository, add the aisus skills.

    2. Run this in Claude Code or Codex.

      $ git add .archify && git commit -m "Add aisus map" && git push
    The map lives in .archify/ next to your code.
    Already committed a map? Skip this step
    Step 4/4

    Publish it from GitHub Actions

    Add one workflow file in one commit.

    .github/workflows/aisus.yml
    name: aisus
on:
  push:
    branches: [main]
  pull_request:
permissions:
  contents: read
  pull-requests: write
  id-token: write
jobs:
  map:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
        with:
          fetch-depth: 0
      - uses: kerktaiheng/aisus/action@main
        with:
          upload: true
          cloud-url: https://aisus.dev
    • GitHub signs each upload. There is no token to keep.
    • It sends maps and check results. Never your code.
    • If GitHub opens a pull request instead, merge it.
    Then press Commit changes on GitHub.
    Not on GitHub Actions? Use an upload token
    Step 4/4

    Publish it from your CI

    Use one command with an upload token.

    Upload token for kerk/checkout-servicecreated just now

    Run it in your CI, on the default branch.

    $ AISUS_TOKEN=aisus_8Hc2Qe7LpZ4mVw1R node aisus.mjs publish --url https://aisus.dev
    Your shell history keeps this token. Store it as a secret in your CI.

    Each aisus release on GitHub comes with aisus.mjs.
