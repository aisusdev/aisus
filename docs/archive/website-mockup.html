how it works

Drawn once by your agent. Checked on every save.

The map lives in your repository, next to the code it describes. Checking it costs no tokens, so it stays right long after the agent session ends.

Your agent draws the map

Press Generate in VS Code, or run /aisus-architecture in Claude Code or Codex. The agent reads the repository and writes a map where every box cites its lines.

Every box opens its code

Click a box and your editor opens the exact lines it cites. On every save aisus checks each citation again, at zero tokens, and marks it fresh, moved, edited or missing.

Pull requests show what they touch

The GitHub Action comments on each pull request with the boxes it touches, the boxes it leaves stale and the code no box covers.
