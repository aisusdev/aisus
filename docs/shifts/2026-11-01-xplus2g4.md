## Proposals

### P-26 Estimates from this folder's runs, and an optional detailed estimate (2026-11-01)

Estimates stay far below what runs spend. This repository's one recorded run spent 1.46M tokens ($1.49) against "About 160k–320k tokens". Every estimate is scaled by the median ratio of spent to estimated tokens over the last five finished runs in the same folder, by the same agent and of the same kind. A new setting, `aisus.estimate.detailed`, is off by default. When it is on, Generate first plans which files the focus will read, then shows the planned reads, turns and tokens and waits for a second click.

The detailed estimate counts each turn's whole context again, because 93% of that run's tokens were cache reads. Tokens are about T × P + R × (T + 1) / 2 + O. T is the planned turns: the tier's read budget plus validator and write turns. P is the prompt and skill per turn. R is the planned read tokens, from the planned files' byte sizes. O is the output. The planned files are those whose paths match the focus words, up to the read budget, and files at the folder's median size fill the rest. The constants start provisional and the folder's runs calibrate them. A past run's prediction is recomputed from today's files and its `focus` in `run.json`, so `run.json` keeps its format.
