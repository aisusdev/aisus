6.3 Evidence

On 9 November a teardown script deleted our server and its only disk. Umami's history went with it. AWS kept the deleted server's network traffic, and section 6.4 estimates the lost visits from it.

Visits turn into installs slowly. Between 330 and 500 people reached the site. GitHub served 68 release files, and the Marketplace served 115. Installing aisus takes one click. Using it needs Node.js, a signed-in Claude Code or Codex, and the user's own tokens. That setup is where we expect most people stop. The live demo in section 1.1 skips all three.

6.4 How we estimated the lost visits

Thankfully AWS keeps a deleted server’s network metrics in CloudWatch for 15 months. We use the new server's traces to calibrate. On quiet days it sends about 7 MB of background traffic. Each page view adds about 0.6 MB on top. The old server sent 686 MB from 24 October to 8 November. Without the background, that is 600 to 1,000 page views. At the new site's ratio of visitors to views, it is 260 to 430 visitors.
