6 Users and analytics

6.1 What we measure

The extension sends no telemetry. aisus reads private code, and we decided that a tool which reports on its users would lose the developers it is for. An optional usage log counts each action per day, stays in VS Code's own storage and leaves the machine only when the user exports it.

Our numbers come from four places outside the extension. The VS Code Marketplace publishes install and download counts for the listing. GitHub counts downloads of each release file, and it reports views and clones of the repository for the last 14 days. Umami counts visits to aisus.dev without cookies. aisus cloud's database holds the accounts that signed in and the maps they uploaded.

On 9 November a teardown script ran by accident and removed the server with its only disk. The cloud's database and Umami's history from before that date were lost. Site and cloud figures therefore cover 9 November onwards.

6.4 User feedback

Two developers tested early builds. Both valued the same thing, the map together with the click from a box into its code. That result is why we kept the map and its link to the code at the centre and cut the rest of our original pitch.

Our interviews changed who we build for. One interviewee reads every line an agent writes, and another avoids autonomous agents altogether. Both care about understanding the code they keep. One interviewee asked why they would not just ask Codex. aisus's answer is a map that stays in the repository, is checked against the code for free and refreshes only what changed. None of the developers we interviewed used VS Code, and that led us to build the IntelliJ IDEA plugin.

6.5 What the numbers show

The numbers fall well short of our plan. We set a gate of about ten teams uploading maps every week before we would charge for aisus cloud. We have five Marketplace installs, no stars on the repository and no team uploading every week.

Four causes explain most of the gap. We held back the public announcements on Show HN and Reddit until the first users' bugs were fixed, and they have not gone out. The extension reached the Marketplace only on 1 November, and before that a user had to download a VSIX and install it by hand. It is still missing from Open VSX, which Cursor uses, because that store needs a licence field we had not settled. The IntelliJ IDEA plugin, built for the users we interviewed, is a zip on GitHub rather than a listing on the JetBrains Marketplace.

Trying aisus also costs more than installing it. A first map needs Node.js and a signed-in Claude Code or Codex, and it spends the user's own tokens. Our own repository's first map spent 1.46 million tokens, about US$1.49, while the estimate said 160k to 320k.

Without telemetry we cannot see where people stop between the listing and a first map. That blind spot is the cost of the privacy choice in section 6.1.
