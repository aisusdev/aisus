4.2 Individual contributions

We worked on main in shifts of a few days. Each shift kept a shift doc with its proposals, a log of decisions and a handover for the next person. The repository holds 369 commits from 10 October to 18 November 2026. Kerk Tai Heng wrote 150 of them, Dinh Duy Linh Dan 120 and Jianxi 99.

Kerk Tai Heng. Kerk wrote the v0.3 specification after the mentor's feedback and built most of it between 18 and 24 October. That work covers the map model and its validator, the extension's sidebar and agent launcher, the freshness check, the first version of aisus cloud and the security fixes the specification called for. Kerk deployed the cloud to one AWS server on 24 October, and wrote the working agreement, hard stops and product rules that every later shift followed.

Dinh Duy Linh Dan. Dan owned aisus cloud and the public site after launch. Dan built the team page, the branch list for repositories without a main map, and the homepage redesign with its tabs, pricing page and getting-started guide. Dan filed and tracked the 17 GitHub issues that set the roadmap, published version 0.3.4 to the VS Code Marketplace, designed the poster, and rebuilt the server after it was removed by accident on 9 November.

Jianxi. Jianxi worked across the shared packages that every surface uses. Jianxi split the code into the core, the viewer, the extension, the cloud and the IntelliJ IDEA plugin, and built the plugin's release step. Jianxi added the skill that posts a diagram on a pull request, moved the cloud's signed-in pages under one account section, scaled token estimates to each folder's past runs, and drew plan maps with new boxes dashed and removed boxes faded. Jianxi released version 0.3.3 and set up this report's framework.

Tools, services and libraries

aisus runs on the coding agents its users already have, and we built it with the same agents. Claude Code, Codex and Devin draw the maps. The extension runs in VS Code, and the plugin is built on the IntelliJ Platform. The map viewer lays out diagrams with elkjs and checks maps against their schema with Ajv. The map format started from the Archify JSON format, which is MIT licensed. aisus cloud uses Next.js, React, Auth.js for GitHub sign-in, Drizzle ORM and PGlite, with Stripe for payments in test mode. It runs on one AWS EC2 server behind Caddy, with Umami for site visits and Prometheus and Grafana for server metrics. The site's headings use the Poppins typeface under the SIL Open Font Licence. Tests run with Vitest, Playwright and the VS Code test runner, and GitHub Actions runs the checks and builds the releases.
