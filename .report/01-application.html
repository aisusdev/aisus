1 The application

1.1 What aisus is

aisus draws a repository as a map. Each box on the map stands for a part of the system and cites the files and lines it describes. A click on a box opens those lines in the editor.

The developer's own coding agent draws the map. aisus gives the agent a skill to follow, and it checks every citation before it saves the map. After that, aisus compares the map with the code whenever the code changes. It marks each box whose code has changed, and the check costs no tokens. Refresh asks the agent to redraw only the marked boxes.

aisus runs as a VS Code extension, an IntelliJ IDEA plugin and a set of agent skills. aisus cloud at aisus.dev shares maps with a team. A GitHub Action reports which boxes each pull request changes.

1.2 The symptom

Software is now written faster than anyone understands it. We call the gap comprehension debt. It costs nothing while the system runs. The bill arrives as an outage, and the team pays it by learning the system under pressure.

Agents do not close the gap. An agent reads a few files at a time, and its picture of the system ends with the session. It can explain one function well and still miss how two services depend on each other.

Microsoft is the clearest case we know. In August 2026 Jay Parikh, Microsoft's executive vice president of CoreAI, wrote to engineers that "tokenmaxxing is not what we are optimizing for." Copilot dashboards had made each engineer's AI spending visible, and for some employees they had turned into something like a leaderboard. In a voluntary internal spreadsheet, the median spend was about US$300 in tokens every 28 days, and one employee reported about US$28,000. November's Patch Tuesday fixed 1,094 vulnerabilities, and Microsoft credited AI for the number.

Two days later Exchange Online went down around the world for 23 hours and 50 minutes. Microsoft's preliminary report traces the outage to a change shipped in July. Under load, the change made gateway servers wait on each other's locks until they ran out of CPU and memory. The defect was worse on newer machines with more cores. Microsoft's load tests ran on weaker machines with fewer cores, and the defect passed them. A routine failover then moved Teams traffic onto the gateway that Exchange uses, while 14% of its servers were already down. More than 80% of the gateway stopped responding. The boundaries meant to hold a failure inside one region did not hold. The change was too old to roll back. Servers that came back up were flooded by waiting traffic and failed again.

Microsoft says AI did not cause the outage, and we do not claim it did. We read the outage as the shape comprehension debt takes. An engineer who knew the gateway inside out would have asked how a lock behaves on a machine with more cores. That engineer would have load tested on the machines that run in production. Nobody asked for four months. A company that counts the tokens its engineers spend is shipping code faster than it understands it, and its customers paid the bill for a day.

Cite Microsoft's preliminary post-incident report (EX1550543 and MO1550821), the 404 Media report of Parikh's memo, Ynet on the spending spreadsheet, and the Patch Tuesday figure.

1.3 The vision

Programming stands at a precipice. Each generation of tools has carried people further from the machine. Assembly was too much, and we wrote C. C was too much, and we wrote Python. Code itself is now too much, and agents write it for us. Each step let people build more while understanding less of what lies beneath.

Two futures wait past the edge. In one, agents reach general intelligence. They understand the systems for us, and most of us are out of a job. In the other, agents stop getting better as fast as they have, and the chain continues. Something must then sit above code, the way code sits above assembly. aisus is our hedge against the first future and our bet on the second.

We predict that the next step is the picture. People understood the world by seeing it long before they read or wrote. Engineers still reach for a whiteboard when they need to explain a system. The chain of abstraction ends where it began, with the way humans meet the world. aisus is a step in that direction. It draws the system as a picture and ties every part of the picture to the code that proves it.
